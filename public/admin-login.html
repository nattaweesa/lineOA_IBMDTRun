Admin Login

เข้าสู่ระบบด้วยบัญชี Google ที่ได้รับสิทธิ์ก่อนเข้าหน้า IBMDT Run Admin

ใช้ Google Sign-In เพื่อยืนยันตัวตนเพียงขั้นตอนเดียว ระบบจะพาเข้าสู่หน้าที่คุณตั้งใจเปิดไว้ให้อัตโนมัติหลังล็อกอินสำเร็จ
  • เข้าใช้งานได้เฉพาะบัญชีที่ได้รับสิทธิ์เท่านั้น
  • Session ถูกเก็บใน cookie ที่ฝั่ง browser อ่านตรงๆ ไม่ได้
  • เมื่อล็อกอินสำเร็จ ระบบจะพากลับไปหน้า admin ทันที
